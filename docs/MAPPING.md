# 기기에 저장된 곡 목록과 TJ 번호 매칭

Android 앱은 사용자가 붙여넣은 YouTube 또는 YouTube Music 링크에서 재생목록 ID를 읽는다. 공식 YouTube Data API로 목록을 페이지 단위로 받아 영상 ID별 제목·채널·설명·일본어 현지화 표기를 연결한다. 기기의 곡목과 일본어 독음 사전으로 TJ 번호를 대조한다.

## 1. 입력과 곡목

- **곡 목록**의 순서와 중복을 유지한다. 다른 언어의 제목은 입력 자료에 같은 곡의 표기로 들어 있을 때 쓴다. 기기에 저장한 목록의 썸네일 주소는 이미지 파일을 처음 표시할 때만 받아 앱 전용 파일에 보관한다.
- **TJ 번호와 후보**는 TJ 공식 일본곡 검색에서 확인한 번호로 제한한다. 가수가 한국인이거나 제목이 한국어인 커버도 같은 일본 원곡이면 그 반주를 찾을 수 있다. 일본곡 번호를 찾지 못한 영상도 플레이리스트에 원래 순서로 표시한다. ☰의 검색창은 저장한 플레이리스트 이름을 검색한다. [번호책](https://github.com/Alfex4936/tj-media-karaoke-api)

## 2. 영상에서 노래와 가수 식별

1. 음원 메타데이터의 제목과 아티스트, 동일 영상의 현지화 표기, 영상 표시 제목을 후보로 모은다. 원문도 보존한다.
2. 전각·반각, 대소문자, 문장부호, 공백을 정규화한다. 공식 영상 태그, 피처링, 작품 설명과 버전 표기는 정해진 형식에서만 해석한다. 슬래시가 들어간 정식 곡명은 통째로 검색할 수 있다.
3. 커버 영상에서는 제목에 명시된 원곡 가수를 우선한다. 단순 업로더나 커버 가수 정보만 있으면 원곡 가수 일치의 근거로 쓰지 않는다. 제목에 원곡자가 없는 커버는 후보를 제시할 수 있다.
4. 가나를 로마자로 변환하고, 한자는 일본어 형태소 사전에서 읽기를 구한다. 사전이 모르는 한자를 임의의 발음으로 대체하지 않는다. 의미가 다른 언어로 번역된 제목은 동일 영상이나 곡목에 해당 별칭이 있을 때 연결할 수 있다.
5. 업로더가 설명에서 원곡을 지정하고 YouTube 영상이 하나로 좁혀지면 공식 API로 그 영상의 제목, 가수와 현지화 표기를 확인한다. 원곡이 여러 개이거나 영상과 원곡이 서로 다른 번호를 가리키면 보류한다. 채널의 영어·일본어·한국어 표기는 같은 채널 ID로 연결한다.
6. 배급사가 제공한 음원 설명에서 제목과 참여 가수를 분리한다. 커버에 작곡자가 명시됐으면 곡명과 그 작곡자의 이름이 TJ의 같은 곡명·가수에 함께 맞을 때 원곡 반주로 표시할 수 있다. 배급사 영상의 인용 제목, 보컬로이드 피처링, 작품명 안의 연도 괄호도 원래 크레딧과 대조한다.

## 3. 로컬 후보 검색과 결정

편곡 커버에서는 영상 제목의 곡명과 설명의 일본어 크레딧을 함께 읽는다. 예를 들어 영상 제목이 『곡명 -Arrange ver.-cover【커버 가수】』이고 설명에 『원곡 가수さんの「곡명」をアレンジカバーしました』라고 적혀 있으면, 인용된 곡명이 영상의 곡명과 일치하는지 먼저 확인한다. 해당 곡명과 원곡 가수로 일본 TJ 번호가 하나일 때 원곡 반주로 표시한다. 설명에 서로 다른 원곡을 적었거나 원곡 영상의 판정과 충돌하면 번호를 보류한다.

커버 제목의 괄호 안에 원제와 가수가 함께 적힌 경우에는 두 표기를 한 쌍으로 대조한다. 예를 들어 `번역 제목 [원제 / 가수] / 커버 가수 Cover`와 `번역 제목 (가수 - 원제) | 커버 가수 Cover`에서 괄호 안의 양쪽을 각각 곡명과 가수로 확인한다. 제목과 가수의 등록 표기가 모두 맞고 가능한 원곡 번호가 하나일 때 원곡 반주로 표시한다. 듀엣·메들리처럼 여러 작품의 크레딧이 보이면 보류한다.

재녹음 표기가 있으면 같은 버전을 먼저 찾는다. 같은 버전이 없을 때 원제 또는 등록 별칭과 가수 표기가 모두 일치하고 버전 표기가 없는 TJ 번호가 하나이면 **원곡 반주**로 표시한다. 다른 가수의 동명곡, 발음만 같은 후보, 여러 원곡 번호는 이 판정에서 제외한다. 커버 가수만 표시된 트리뷰트는 원곡자 크레딧 등 별도 자료가 필요하다.

- 제목과 가수의 원문·별칭·독음으로 로컬 색인을 만든다. 제목 완전 일치와 독음 일치로 후보 번호를 모은 뒤 가수를 대조한다. 유튜브 채널 접미사와 공인된 곡목 별칭을 함께 처리한다.
- 로마자에 장음이 생략된 경우와 TJ에 실린 한글 독음을 보조 표기로 비교한다. 가수 근거와 함께 사용하며 원제의 정확한 철자를 우선한다. 일본어 제목만 맞고 가수를 확인할 수 없으면 유일한 원제 후보도 확정 번호와 구분한다.
- **자동 확정**은 제목 근거와 가수 근거가 모두 있고 가장 강한 근거를 가진 번호가 하나일 때 가능하다. 동명이곡, 가수 충돌, 원곡자 미상, 구분할 수 없는 여러 버전은 **확인 필요**로 남긴다. 부분 문자열이나 가수 한쪽만으로 번호를 확정하지 않는다.
- 제목 후보까지 없으면 **목록에서 못 찾음**, 비공개·삭제된 영상은 **스킵**으로 기록한다. 로컬 목록의 범위와 기준일을 고려해 미검색을 TJ 미수록으로 단정하지 않는다.
- CSV에 원본 제목, 업로더, 영상 ID, 검색 표기, 상태, 판정 근거, 확인 후보를 남긴다. 확정한 행에만 TJ 곡번호를 쓴다. 플레이리스트의 입력 순서와 중복 항목을 보존한다.

## 4. 구현과 검증

사람이 보컬로이드 곡을 부른 영상에는 같은 작품의 TJ 반주 번호를 표시할 수 있다. VocaDB에 연결된 원곡·커버 영상 ID, 공개 작품의 곡명·번역명, 크레딧을 사용한다. 커버 가수와 등록 가수가 달라도 원곡을 식별하면 **같은 곡 TJ**로 표시한다. 동명의 다른 작품이나 상충하는 원곡 출처가 있으면 보류한다. 앨범명과 작곡진만 일치하는 경우에는 **TJ 후보**로 표시하며 확정 건수에서 제외한다.

한국어 설명의 `곡명`, `노래 제목`, `곡 제목`과 `원곡 가수` 또는 `원곡자`는 한 쌍으로 읽는다. 곡명이 하나이고 원곡자가 하나일 때 번호책과 함께 대조한다. 원곡자나 작곡자 표기가 등록 크레딧과 충돌하면 확정과 후보에서 모두 제외한다. 단일 언어의 작품명에 하이픈·자막 표시만 붙은 커버는 곡명을 후보로 제시할 수 있다. `원본 다시보기`, `일러스트`, 용도가 적히지 않은 `출처:`의 링크는 원곡 식별에 사용하지 않는다.

플리 제목 옆 **재탐색**은 저장된 모든 행을 현재 곡목과 규칙으로 다시 계산한다. 이전 번호도 재검증하며 순서, 중복, 사용자가 고른 사진을 보존한다. 예전 버전의 목록에는 원곡 영상 설명이 없으므로, 버튼을 누르면 공식 API에서 이 정보도 보충한다. 오프라인에서는 기기에 있는 자료로 계산한다. 보관 기한이 지난 YouTube 목록은 공식 API에서 갱신한다. 매칭 리비전이 바뀌면 처음 목록을 열 때 저장한 자료부터 다시 계산한다.

1. `src/import_catalog.js`로 원본 JSON을 검증하고 로컬 곡목을 저장한다.
2. Android는 `mobile/ui/youtube.js`에서 전체 페이지 조회가 끝나면 목록을 한 번에 저장한다. 같은 링크의 중복 영상과 순서를 유지한다. API 데이터는 기기에서 최대 30일간 보관하며 이후 열 때 갱신한다. PC는 `src/playlist.js`에서 기존 입력을 해석한다.
3. `src/matching.js`의 매칭 규칙을 Android의 `mobile/ui/worker.js`와 CLI의 `src/tj_search.js`에서 공유한다. 가타카나 외래어의 ヴ·バ행 차이는 원제 완전 일치 다음 순위로 처리한다. 유튜브 채널의 슬래시 뒤에 앞의 활동명이 반복되는 공동 명의가 있으면 가수 후보에 포함한다. CLI에서 CSV와 대조용 텍스트를 생성한다.
4. 입력의 행 수·순서와 확정·보류 결과를 확인한다. 동명곡의 가수 구분, 로마자·가나·한자 입력, 커버와 버전 모호성, 숫자·기호가 있는 제목, 언어별 순서가 달라진 플레이리스트를 테스트한다. 테스트에서 처음 만든 가상의 곡도 같은 규칙을 통과해야 한다.

새 플레이리스트의 정확도를 조사할 때는 번호가 없는 항목과 확인 후보를 모두 대조한다. 각 곡의 원제, 확인 가능한 별칭, 버전을 뺀 제목으로 TJ 공식 검색을 수행하고 가수 전체 곡목과 교차 확인한다. 공식 번호가 있으면 로컬 곡목의 번호·가수와 매칭 입력을 비교해 곡목 누락, 표기 처리 오류, 원곡자·버전 정보 부족 중 실제 원인을 기록한다. 공식 번호를 확인할 수 없는 곡도 검색어와 동명이곡 배제 근거를 남긴다. 이 조사는 앱의 오프라인 매칭과 별도로 수행한다.

## 구현에 사용한 데이터와 도구

로컬 매칭은 kuromoji의 형태소 사전과 WanaKana의 문자 변환을 사용한다. 원본 곡목에 기계 번역으로 표시된 한국어 제목은 검색 별칭에서 제외한다. 동일 곡의 현지화 제목이 없고 의미 번역만으로 연결할 수 있는 경우에는 결과가 비어 있을 수 있다. 커버에서 원곡 가수 정보가 없는 경우도 자동 확정을 보류한다.
