개인정보 처리방침

플리를 등록하면 앱이 Google의 YouTube Data API로 목록 ID와 영상 ID를 보내 제목·채널·설명·썸네일을 받습니다. 이때 Google에 접속 IP와 앱 식별 정보가 전달됩니다. TJ 번호는 기기의 곡목으로 찾습니다.

목록과 직접 선택한 사진은 기기에 저장됩니다. YouTube 조회 정보와 내려받은 이미지는 최대 30일간 보관하며, 만료된 목록은 다시 열 때 갱신합니다. ☰에서 저장한 목록을 삭제할 수 있습니다. 앱 데이터를 지우면 기기에 저장된 목록과 사진도 삭제됩니다.

앱은 업데이트 확인을 위해 GitHub에 접속합니다. 운영자는 별도 서버에서 플리나 개인 정보를 수집하지 않습니다. YouTube 기능을 사용하면 YouTube 이용약관이 적용됩니다. Google 개인정보처리방침 · 개발자 문의
