# 유플리집

휴대폰에 저장한 곡 목록에서 TJ 노래방 번호를 찾는 Android 앱입니다. 곡명과 가수를 기기의 일본곡 번호표와 대조하며 오프라인에서도 검색할 수 있습니다.

## 설치

[최신 유플리집 다운로드](https://github.com/Nyancode1/yuplijip/releases/latest)에서 APK를 받아 설치하세요. Android 9 이상과 최신 Android System WebView를 지원합니다.

기존 1.4 또는 1.5 사용자는 **1.5.1을 한 번 직접 덮어설치**하세요. 앱을 먼저 삭제하면 저장한 목록도 지워집니다. 1.5.1부터는 앱을 열 때 새 정식 릴리스를 확인합니다. **업데이트**를 누르면 앱이 설치 파일을 내려받고 Android 설치 화면을 엽니다.
